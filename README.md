# Super Portfolio World

This repository contains the source code for a **Mario-inspired personal portfolio** website. It features a unique 8-bit aesthetic with animated pixel-art sections, interactive levels, and a nostalgic "World 1-1" loading experience.

## 🎮 Features

* 
**Mario-Themed Design**: Includes custom pixel-art components like `PixelBlock` (brick, question, and floor types) and a `PixelCharacter`.


* 
**Interactive Loading Screen**: A themed "World 1-1" loading screen with a progress bar and animated status updates.


* 
**Smooth Animations**: Leverages `framer-motion` for staggered section reveals, spring transitions, and floating animations.


* 
**Dynamic Sections**: Organizes content into Home, About, Skills, Experience, Projects, and Certificates.


* 
**Responsive Layout**: Built with a mobile-first approach using Tailwind CSS.


* 
**AI Integration**: Configuration prepared for Google Generative AI (Gemini).



## 🛠️ Tech Stack

* 
**Frontend**: React (v19) 


* 
**Build Tool**: Vite 


* 
**Styling**: Tailwind CSS 


* 
**Animations**: Framer Motion 


* 
**Language**: TypeScript 


* 
**Icons**: React Icons 



## 📂 Project Structure

* 
`src/App.tsx`: The main application entry point and layout logic.


* `src/components/`:
* 
`PixelBlock.tsx`: Customizable 8-bit styled containers.


* 
`PixelCharacter.tsx`: Animated pixel-art character component.




* 
`src/constants.tsx`: Centralized data for projects, skills, and professional experience.


* 
`src/types.ts`: TypeScript interfaces for core data structures.



## 🚀 Getting Started

1. **Clone the repository**.
2. **Install dependencies**:
```bash
npm install

```




3. **Run Development Server**:
```bash
npm run dev

```


The app will be available at `http://localhost:3000`.
